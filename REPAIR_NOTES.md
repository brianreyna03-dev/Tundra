# TMMTX Unit Plant Shift Board

This archive uses the standard Vite project layout and intentionally excludes
`node_modules` and lockfiles so CodeSandbox can install cleanly from the public
npm registry.

## Run

```bash
npm install
npm run dev
```

The included `.npmrc` points to `https://registry.npmjs.org/`.

The project was build-tested with:

```bash
npm run build
```
