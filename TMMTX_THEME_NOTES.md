# TMMTX Unit Plant Theme

This version uses a clean industrial visual system built around charcoal, steel,
white, and a red plant accent. It does not require any external fonts or images.

## Main changes

- TMMTX Unit Plant operations header and live roster metrics
- Red/charcoal industrial dashboard styling
- Coverage-focused wording for board, team, and process screens
- Team-member status cards with initials and certification counts
- Process coverage indicators and a visible coverage-gap alert
- Updated example data for Unit Assembly, Sub-Assembly, and Material Support
- Print-friendly coverage board

## Run

```bash
npm install
npm run dev
```
